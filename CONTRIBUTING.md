## Features

- Visual agent builder with drag-and-drop role, tool, and handoff configuration
- Multi-agent orchestration engine supporting sequential, parallel, and supervisor patterns
- Built-in task queue with scheduling, retries, and run history for every agent team
- Connector library for local files, REST APIs, databases, and messaging platforms
- Live execution trace viewer with per-step logs, token usage, and cost breakdowns
